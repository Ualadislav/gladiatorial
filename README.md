# Gladiators Mini App

Рабочий MVP игры 1 на 1 для Telegram Mini Apps: неподвижная 2D-арена, бой против тренировочного соперника, блок с окном точного тайминга, урон и полосы здоровья, прокачка, золото и косметические облики.

## Стек

- **Игра:** Phaser 3, TypeScript, Vite.
- **API:** Node.js 22, Fastify, PostgreSQL.
- **Развёртывание:** Docker Compose; Caddy автоматически выпускает HTTPS-сертификат для домена.
- **Вход:** проверка подписи Telegram `initData` на сервере; без Telegram игра доступна локально, а прогресс сохраняется в браузере.

## Разработка на Windows 10

Нужны Node.js 22+ и Docker Desktop.

```powershell
npm install
npm run dev
```

Откройте показанный Vite адрес. В обычном браузере игра запускается в автономном режиме. Для локальной проверки API задайте `ALLOW_DEV_AUTH=true`, `DATABASE_URL` и `WEB_ORIGIN=http://localhost:5173`, затем запустите PostgreSQL и выполните `npm run dev:server` в отдельном терминале.

Проверки:

```powershell
npm run typecheck
npm run build
```

## Развёртывание на Ubuntu VPS

Скопируйте или клонируйте проект на VPS и из корня проекта выполните:

```bash
sudo bash scripts/install-ubuntu.sh
```

Скрипт установит Docker Engine и Compose Plugin из официального репозитория Docker, запросит домен и токен бота, сгенерирует пароль PostgreSQL и запустит приложение. Для Telegram Mini App нужен домен с A-записью на белый IP сервера: Caddy получает и продлевает HTTPS-сертификат автоматически. Разрешите входящие TCP-порты **80 и 443** в сетевом firewall VPS; также должен быть доступен порт SSH.

Создайте бота через [@BotFather](https://t.me/BotFather), сохраните выданный токен в `.env`, укажите домен, а затем настройте URL Mini App у бота. Не публикуйте `.env`: в нём находятся секреты. PostgreSQL наружу не открыт.

Локальный предпросмотр без домена слушает `127.0.0.1:8080` и не подходит для запуска Telegram Mini App, которому необходим HTTPS. Когда DNS домена начнёт указывать на VPS, добавьте его в `.env` (`APP_DOMAIN` и `WEB_ORIGIN`) и выполните:

```bash
docker compose --profile public up -d --build
```

Полезные команды:

```bash
docker compose ps
docker compose logs -f server
docker compose --profile public up -d --build
```

## Примечания к MVP

- Сражение с ботом и его награды пока рассчитываются на клиенте — это прототип механики, а не защищённый PvP. Не подключайте к нему платные покупки или ценные награды до переноса симуляции боя на сервер.
- Сервер проверяет подпись Telegram и хранит профиль, покупки косметики и прокачку в PostgreSQL. В браузере без Telegram используется локальное сохранение.
- Графика бойцов рисуется программно, поэтому прототип не зависит от загружаемых игровых ассетов.
